# House Price Prediction & Analysis

## Overview
This project analyzes housing data from King County, Washington to determine which factors have the greatest impact on house prices. The project includes data cleaning, exploratory data analysis, data visualization, and machine learning to examine relationships between housing characteristics and sale prices.

## Research Question
Which factors have the greatest impact on house prices?

The analysis focuses on variables such as:
- Square footage
- Bedrooms
- Bathrooms
- Land value
- Improvement value

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses King County housing data containing information about residential properties and their sale prices.

The dataset includes variables related to property size, bedrooms, bathrooms, land value, improvement value, and other housing characteristics.

## Data Analysis
The analysis included:

- Cleaning and preparing the housing dataset
- Checking for missing values and irrelevant variables
- Exploring distributions and relationships between variables
- Identifying and handling outliers
- Creating correlation heatmaps and scatter plots
- Comparing housing characteristics with sale price
- Preparing the data for predictive modeling

## Machine Learning
A regression model was used to examine how well housing characteristics could predict house prices.

The data was separated into training and testing sets so that the model could be evaluated on data it had not previously seen. Predicted house prices were then compared with actual house prices to evaluate model performance.

## Key Findings
The analysis showed that housing characteristics related to property size and value were important when examining differences in house prices.

The model showed a strong relationship between predicted and actual prices for many homes, although prediction became more difficult for extremely high-priced properties.
